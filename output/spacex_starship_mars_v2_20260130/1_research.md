### 2. 주요 기술/시스템

| 기술명 | 특징 |
|--------|------|
| **Raptor 3 엔진** | 더 강력하고 제조 용이, 외부 배관 제거 |
| **Mechazilla (젓가락 팔)** | 부스터 직접 캐치 회수 시스템 |
| **MOXIE** | 화성 대기 CO2 → O2 전환 기술 (Perseverance 탑재) |
| **ISRU (In-Situ Resource Utilization)** | 현지 자원 활용 기술 |
| **ECLSS** | 폐쇄 루프 생명유지시스템 (ISS 사용) |
| **Kilopower** | 소형 원자력 발전 시스템 |
| **레골리스 3D 프린팅** | 화성 토양 활용 건축 기술 |

### 3. 개발 타임라인

| 연도 | 마일스톤 |
|------|----------|
| 2024 | Flight Volume - 다중 발사, 부스터 캐치, 궤도 엔진 재점화 |
| 2025 | Orbital Refueling - 선박 간 추진제 이송 테스트 |
| 2026 | 무인 화성 착륙 시도 (첫 Launch Window) |
| 2026 (9월) | Artemis III 달 착륙 (NASA HLS) |
| 2028-2030 | 첫 유인 화성 탐사 |
| 20년 이내 | 화성 자립형 도시 건설 목표 |

### 4. 기술적 진행 상황 (2024년 말 기준)

- **IFT-5 성공**: 슈퍼 헤비 부스터를 발사대에서 Mechazilla로 직접 회수
- **Starship V2**: 추진제 용량 증가, 건조 질량 감소, 신뢰성 향상
- **다음 단계**: 궤도 내 연료 이송 테스트, 대기권 재진입 정밀 착륙 고도화

### 5. 화성 인프라 기술

| 분야 | 기술/방법 |
|------|----------|
| **대기 개조** | 극지방 드라이아이스 융해, 온실가스 방출, 인공 자기장 |
| **산소 생성** | CO2 전기분해 (MOXIE 검증됨) |
| **수자원** | 지표 하 얼음 시추, 전기분해로 H2/O2 분리 |
| **건축** | 레골리스 + 3D 프린팅 |
| **에너지** | 태양광 + 소형 원자력 (Kilopower) |
| **통신** | 지구-화성 레이저 통신망 |
| **생태계** | 남조류/이끼류 → 단계적 테라포밍 |
